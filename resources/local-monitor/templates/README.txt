Local Monitor default templates
===============================

These image_*.png swatches are 11-12px crops of EVE Online pilot-name colours,
copied from the EVE-Alert project (https://github.com/Geuthur/EVE-Alert), which
is licensed under GPL-3.0. They are bundled as REPLACEABLE DEFAULTS only — the
Local Monitor engine logic itself is an original reimplementation and no GPL
code enters this repository.

To supply your own templates, put .png/.jpg screenshots of the enemy/neutral
pilot-name colours you want to match into any folder and set that folder in the
app's settings (localTemplateDir). An empty setting uses these bundled swatches.
